# Bob check-in

The digest that comes with this text lists what changed since the last check-in: sessions,
checkouts, calendar, PRs and tickets. It also lists flags drawn from the block ledger. Both files
below sit in `~/.agents/skills/nbr-bob/`. Read them fresh now, even when this session read them
earlier.

1. Read `blocks.md`. Bring every circle's time blocks in line with the digest's signals, as that
   file says. Handle every block flag in the digest.
2. Read `filing.md` before updating todos. Then update every todo the digest shows stale, in the
   daily and the monthly note, by its rules. Tick what a merged PR, a pushed commit or a lifted
   review shows done.
3. Write each weekly the digest lists as due, as the circle skill says. Update a weekly that is
   still open before its meeting with the work that finished or started in its circle.
4. Ask each idle session that Bob drives and that has unreported work for its report. Send the ask
   with `SendMessage`. Leave busy sessions alone.
5. Read a Rex pane, a PR or a ticket only where the digest leaves its state unclear.
6. Tell Nik what changed or needs him, one line each. Say what waits on him first. Name a meeting
   that starts before the next check-in. While a meeting runs, the news waits for its end. When
   nothing needs Nik, end the turn without text.

Done when every flag is handled, the blocks match the signals, and every stale todo shows its
current state.
