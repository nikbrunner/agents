# Words

Plain replacements for the words that mark machine-written text. Read this list before a draft or any durable prose goes
out, and use the right-hand word or cut the phrase. A Stop hook in Claude Code checks every reply against the table, so a
word in the table is one that has no technical sense in my work.

## Forbidden

Each row holds the forms to catch, comma-separated, then the plain replacement. The hook reads only the table under this
heading: keep it one table, with no `|` inside a cell. Rows are in our own words; the ASD-STE100 dictionary, its
definitions and its example sentences never go into this public repo.

## Check by hand

These words have a technical sense in my work (an API key, a robust parser, syntax highlighting, a feature gate, CSS
alignment, the underscore character, elevated permissions, an auth realm, CPU utilization), so the hook leaves them alone.
In prose, a figurative use is a tell: key (adjective), robust, highlight (verb), gate, align with, landscape, underscore
(verb), enhance, elevate, realm, actually, quietly, valuable, enduring, profound, renowned, groundbreaking, ensure.
